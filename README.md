# MoSeq Toolkit

A Streamlit app and Python library for analyzing MoSeq behavioral sequence data. It takes a raw per-frame MoSeq dataframe (syllable labels, kinematics, timestamps) and turns it into the tables and plots a behavioral analysis usually needs: syllable and cluster usage, scalar and histogram summaries, transition matrices, group comparisons with automatic paired/unpaired and parametric/nonparametric test selection, and cross-validated classifiers for comparing feature sets. It supports both cross-sectional and longitudinal (multi-timepoint) study designs, stratifying comparisons by timepoint automatically so repeated visits from the same subject aren't pooled together.

Everything is driven from `app.py`: upload a dataset in the sidebar, pick your grouping variables (treatment, sex, genotype, etc.) and velocity column, and click through the Usage & Clusters, Scalars, Transitions, and Classifier tabs in whatever order fits the analysis. Each tab's outputs feed the next, and every plot renders as either an interactive Plotly figure or a static matplotlib/seaborn figure matching standard analysis-notebook conventions, switchable from the sidebar without recomputing anything. The underlying library (`ingest/`, `features/`, `stats/`, `classify/`, `viz/`) is also usable directly from a notebook or script for anyone who wants the tables without the UI.

To run it locally: `pip install -r requirements.txt` then `streamlit run app.py`. The app expects a CSV or Parquet file with the standard MoSeq per-frame columns (`SubjectName`, `SessionName`, `frame index`, `labels (usage sort)`, centroid and kinematic columns); a `timepoint` column is optional and only needed for longitudinal studies.
